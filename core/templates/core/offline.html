Local connection options

Use a saved local shop-server address only if the public shop address is unavailable and this device is on the shop Wi-Fi.

Local switching is manual. Android browsers do not let this public HTTPS page silently test private LAN addresses. Choose the correct till and address below. The local sign-in is a separate browser session; sign in again before selling.

No local addresses are saved on this device. While online, sign in and open a shift on each till once to save its configured addresses.

If you have an unfinished sale, return to its original server when it is available; an open cart does not transfer between browser sessions.
