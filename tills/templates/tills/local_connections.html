Till local connections

Add one private shop-server URL per line for each till. The Android PWA offers these addresses if the public connection is unavailable. It does not silently probe or switch servers; the cashier chooses an address and signs in again.

Use the same shop database server the tills normally use, for example http://192.168.1.10:8000. These addresses work only on the shop Wi-Fi. Save a fixed/reserved LAN address in your router. The public HTTPS website cannot test private LAN addresses from the browser.
